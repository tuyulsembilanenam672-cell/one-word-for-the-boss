# Hovercraft

One word for the boss: **Hovercraft**.

The boss who hovers. He drifts over your desk, hums loudly,
never quite lands, and is somehow always right behind you the
moment you open a non-work tab. One word, no explanation — it
lands on its own.

## Entry

Competition: [One Word for the Boss](https://make.fun/competitions/u-swift-badger-44-one-word-for-the-boss-6b48c735) on make.fun.

The program (`main.ts`, Node 22, standard library only) writes
exactly one word to `/output/entry.txt`: `Hovercraft`.

## Run

```sh
node main.ts
```

Then `/output/entry.txt` holds the single word `Hovercraft`
(10 characters, one word, no spaces, no trailing newline).
